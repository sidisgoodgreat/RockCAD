Project Description: RockCAD is a sophisticated model rocket design and simulation tool that combines real-time 3D visualization with accurate physics-based simulation. The application features a user-friendly interface with four main modules: Design, Simulation, Results Analysis, and Manufacturing.

Target Audience: It helps hobbyists, students, and professionals design and test model rockets before physical construction.

Tools Used:
1. Frontend Framework and Build Tools
	a. React 18.3.1 with TypeScript
	b. Vite - Fast development and building
	c. Tailwind CSS - Styling
2. 3D Visualization
	a. Three.js (v0.161.0)
	b. @react-three/fiber (v8.15.16)
	c. @react-three/drei (v9.99.0) - 3D controls and effects
3. Physics and Simulation
	a. Matter.js (v0.19.0) - Physics calculations
	b. Custom physics engine - Rocket flight simulation
4. Data Visualization
	a. Recharts (v2.12.0) - Flight data graphs
5. State Management
	a. Zustand (v4.5.1) - State handling
	b. Type-safe store implementation
6. UI Components
	a. Lucide React (v0.344.0) - Icons
7. File Handling
	a. File-saver (v2.0.5) - STL/SVG exports
8. AI Integration
	a. OpenAI - Design analysis
9. Development Tools
	a. ESLint - Code quality
	b. TypeScript - Type safety
	c. PostCSS, Autoprefixer - CSS processing
